# porto-cleo

Portfolio dan CV personal untuk Cleo Raffadya Rachma - Graphic Designer.

## Deskripsi

Proyek ini adalah halaman portfolio dan CV modern yang menampilkan profil pribadi, keahlian, riwayat pendidikan, proyek, dan informasi kontak. Dibuat dengan HTML dan CSS murni dengan desain responsif dan animasi yang menarik.

## Fitur

- ✨ Desain modern dengan tema gelap dan gradient neon
- 📱 Layout responsif untuk desktop dan mobile
- 👤 Profil pribadi lengkap dengan informasi kontak
- 🎨 Bagian keahlian (skills) dengan ikon visual
- 🎓 Timeline riwayat pendidikan
- 📁 Showcase proyek/portfolio
- 🔗 Link social media (Instagram, LinkedIn, GitHub)
- 📞 Tombol kontak (Email, WhatsApp, Instagram)
- 🎭 Animasi halus dan hover effects
- 🌈 Color scheme: ungu neon, cyan, dan pink

## Teknologi

- HTML5
- CSS3 (CSS Variables, Flexbox, Grid, Animations)
- Font Awesome Icons
- Google Fonts (Plus Jakarta Sans, Space Grotesk)

## Cara Menggunakan

1. Clone repository ini
```bash
git clone https://github.com/cleoraffadyarachma-hash/porto-cleo.git
```

2. Buka file `index.html` di browser
3. Atau gunakan live server untuk development

## Struktur Proyek

```
porto-cleo/
├── index.html              # Halaman utama portfolio
├── README.md               # Dokumentasi
├── .gitignore              # File yang diabaikan Git
└── assets/
    └── images/             # Folder untuk gambar
```

## Kustomisasi

Untuk mengedit konten:
- Buka `index.html` dan ubah teks sesuai kebutuhan
- CSS inline disimpan dalam tag `<style>` di dalam file HTML
- Ganti link social media dan kontak dengan data asli
- Update bagian proyek dengan portfolio yang sebenarnya

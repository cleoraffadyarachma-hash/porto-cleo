# porto-cleo

Portfolio dan CV personal untuk Cleo Raffadya Rachma.

## Deskripsi

Proyek ini adalah halaman portfolio dan CV sederhana yang menampilkan profil pribadi, informasi kontak, dan riwayat pendidikan. Dibuat dengan HTML, CSS, dan desain responsif.

## Fitur

- Desain modern dengan tema gelap
- Layout responsif untuk desktop dan mobile
- Informasi personal lengkap
- Timeline riwayat pendidikan

## Cara Menggunakan

1. Clone repository ini
2. Buka file `index.html` di browser
3. Atau gunakan live server untuk development

## Struktur Proyek

```
porto-cleo/
├── index.html          # Halaman utama
├── README.md           # Dokumentasi
└── .gitignore          # File yang diabaikan Git
```

## Pengembangan

Untuk mengedit konten:
- Buka `index.html` dan ubah teks sesuai kebutuhan
- CSS inline disimpan dalam tag `<style>` di dalam file HTML

## Lisensi

Proyek ini tersedia untuk penggunaan personal.
